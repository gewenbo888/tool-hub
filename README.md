# Tool Hub · 工具集

A focused set of nine free, fast, no-signup online utilities built for everyday use and viral sharing. Bilingual EN ↔ 中文 toggle. Zero-tracking, fully client-side.

## Tools

| | EN | 中文 | URL |
|---|---|---|---|
| 1 | JSON Formatter | JSON 格式化 | `/json-formatter` |
| 2 | Regex Tester | 正则测试 | `/regex-tester` |
| 3 | QR Code Generator | 二维码生成 | `/qr-code-generator` |
| 4 | Password Generator | 密码生成器 | `/password-generator` |
| 5 | Markdown Preview | Markdown 预览 | `/markdown-preview` |
| 6 | Image Compressor | 图片压缩 | `/image-compressor` |
| 7 | Image Cropper | 图片裁剪 | `/image-cropper` |
| 8 | Calculator | 计算器 | `/calculator` |
| 9 | Unit Converter | 单位换算 | `/unit-converter` |

## Features

- **Bilingual** — EN/中文 toggle with localStorage persistence
- **Dark / Light** themes
- **Shareable URLs** — every tool can encode its current state into a hash-fragment link
- **Embed iframe** snippet on every tool page
- **Local-first** — nothing uploaded; tools run entirely client-side
- **SEO-optimized** — separate routes per tool, structured data, FAQ, hreflang
- **Recently used + Favorites** via localStorage
- **Random tool** discovery button

## Stack

Plain HTML + CSS + vanilla JS. Two CDN dependencies: `qrcode.js` for QR rendering, `marked` + `DOMPurify` for safe markdown.
